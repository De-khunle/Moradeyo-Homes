# Moradeyo Homes landing page

A real-estate agency 

## Run it

    npm install
    npm run dev

Then open http://localhost:5173

## Where things are

    src/
      main.jsx            starts the app
      App.jsx             puts all the sections together
      data.js             ALL the text, properties and reviews
      index.css           ALL the styling
      components/
        Navbar.jsx        top menu
        Hero.jsx          big heading + search box
        Services.jsx      what the agency does
        Properties.jsx    filters + list of properties
        PropertyCard.jsx  one property
        Process.jsx       how buying works
        Testimonials.jsx  client reviews
        Contact.jsx       contact form
        Footer.jsx        bottom of the page
